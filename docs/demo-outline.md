# Release demonstration outline

Target: under five minutes, using the [deployed application](https://fardinak.github.io/torob-aipe-challenge/).
This prepares the later recording/submission; neither is part of #22. Prices below
are retained published tariffs, not live stock, a performance promise or a complete bill.

1. **0:00–0:40 — Discover.** Start at the clean homepage. Search `پستگرس`;
   show managed database results rather than recommendations to install it on VPS.
   Explain separate VPS and same-engine price groups. Category buttons offer entry
   without a query; the 16 database engine identities come from admitted offers.
2. **0:40–1:25 — Narrow and inspect.** Choose database / PostgreSQL / 18.4,
   exact 2 CPU / 4 GB RAM / 40 GB disk. Inspect Liara Base at 4,125,000 toman.
   Expand service/evidence details: provider monitoring, unknown topology/location,
   unresolved backup claims, mandatory charges and visible successful-review date.
   Switch to MySQL / 8.4 / exact 4 CPU / 8 GB / 80 GB for Weblines at 6,024,960.
   Show that changing engine clears version; minimum mode also admits larger sizes.
3. **1:25–2:10 — Compare a real exact item.** Open
   `?category=vps&resourceMode=exact&cpu=1&ram=1&disk=10&provider=irvm,mehranhost`.
   The NVMe item has IranVM 545,000 and MehranHost 680,360 toman offers. Expand
   first-party/retained evidence, including the distinct monthly/730-hour basis.
   Filter to MehranHost: starting price becomes 680,360. Provider catalog shows
   that provider's admitted offers at its own bases. A low base budget preserves
   an empty result and its constraints; remove the budget to recover.
4. **2:10–3:10 — Explain the traffic ordering change.** Open
   `?category=vps&ram=4&provider=manageit,iranserver`.
   Base ordering starts at ManageIT 1,420,000. Enter 1,000 GB outbound and explicitly
   select traffic mode: IranServer NGP-small40 leads at 2,436,399; ManageIT shows
   `1,000 GB × 1,200 = 1,200,000` traffic and
   `1,420,000 + 1,200,000 = 2,620,000` subtotal. At 1,200 GB, ManageIT is
   2,860,000; five IranServer offers are outside ranking because required overage
   is unknown. Collapse controls: mode/usage assumptions remain visible. Database
   engines never receive this traffic policy; base budgets do not cap final bills.
5. **3:10–4:00 — Restore and hand off.** Select an offer, copy its URL, reload,
   and use browser Back/Forward. On mobile open/close filters, select a lower list
   item and return to its position. Open the chosen provider's handoff in a new
   tab, cancel the five-second countdown, inspect cost/source warnings, then use
   Continue now. Explain the disclosed general tariff destination and need to
   confirm capacity/conditions. No purchase or login is necessary.
6. **4:00–4:50 — Explain decisions and limits.** Static React/TypeScript/Vite,
   reviewed JSON and retained evidence require no backend or application secrets.
   One comparison operation controls filtering, exact grouping and prices; unknowns
   cannot manufacture eligibility. Show production-base-path tests and deployed
   CI evidence linked from #22. Describe AI-assisted implementation, source review,
   tests and two-axis review; human choices set the problem, traffic assumptions
   and the approved database completion boundary. The app itself calls no AI model.
   Database custom/shared families remain documented gaps under the explicit
   “Publish verified configurations; retain gaps” decision. No exhaustive-market,
   live-availability or unconditional complete-bill claim is made.

If a provider changes its page before recording, present retained dates honestly
and follow the [refresh procedure](catalog-maintenance.md), rather than quietly
changing the worked numbers or treating a failed request as withdrawal.

# Issue tracker: GitHub

Issues and specs live in Fardinak/torob-aipe-challenge.
Use the gh CLI with --repo Fardinak/torob-aipe-challenge.

- Publish specs and tickets as GitHub issues.
- Use --body-file for multiline issue bodies and comments.
- Read issue bodies, labels and comments before acting.
- Apply triage labels using the triage-labels.md mapping.

PRs as a request surface: no.

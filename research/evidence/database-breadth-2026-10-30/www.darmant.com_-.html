مشاهده دیتابیس‌ها شروع

دیتابیس‌های پشتیبانی شده

انتخاب بهترین دیتابیس برای پروژه شما

MySQL

محبوب‌ترین دیتابیس رابطه‌ای برای وب‌سایت‌ها و اپلیکیشن‌ها

  • • سازگاری کامل با PHP
  • • پشتیبانی از UTF-8
  • • بهینه‌سازی خودکار
  • • بک‌آپ خودکار

PostgreSQL

دیتابیس پیشرفته و قدرتمند برای اپلیکیشن‌های پیچیده

  • • پشتیبانی از JSON
  • • Full-text search
  • • ACID compliance
  • • Extensibility بالا

MongoDB

دیتابیس NoSQL برای اپلیکیشن‌های مدرن و مقیاس‌پذیر

  • • Document-oriented
  • • Schema-less
  • • Sharding خودکار
  • • Real-time analytics

Redis

دیتابیس کلید-مقدار برای کش و session management

  • • In-memory storage
  • • سرعت فوق‌العاده
  • • Pub/Sub messaging
  • • Data persistence

SQLite

دیتابیس سبک و سریع برای اپلیکیشن‌های کوچک

  • • Serverless
  • • Zero configuration
  • • Cross-platform
  • • ACID compliant

MariaDB

فورک قدرتمند MySQL با بهبودهای اضافی

  • • سازگاری کامل با MySQL
  • • Performance بهتر
  • • Storage engines بیشتر
  • • Open source

تفاوت در جایی است که سرور تحویل داده می‌شود، نه در نحوه احراز هویت.

ManageIt API

پلتفرم سرور ابری منیجیت
https://api.manageit.dev/api

پروژه‌ها، سرورها همراه با IPها و اسنپ‌شات‌ها، کلیدهای SSH، و لود بالانسرها همراه با دامنه‌ها و شبکه‌های خصوصی. ۴۲ اندپوینت در ۱۲ گروه.

Projects Server Catalog Servers Server Assistant Server Power Server IPs Snapshots SSH Keys Load Balancer Catalog Load Balancers Load Balancer Domains Load Balancer Private Networks

ManageIt Hetzner API

سرور روی Hetzner، DigitalOcean و Linode
https://hetzner.manageit.dev/api

کاتالوگ (ریجن، ایمیج و پلن)، چرخه عمر سرور (ساخت، تغییر اندازه، نصب مجدد، روشن و خاموش، بکاپ)، IPهای شناور و تراکنش‌های صورتحساب. ۱۶ اندپوینت در ۶ گروه، با سقف ۶۰ درخواست در دقیقه به ازای هر توکن.

Server Catalog Servers Server Actions Backups Floating IPs Transactions

شروع سریع

توکن دسترسی شخصی را در https://console.manageit.dev/profile/tokens بسازید و در هدر Authorization بفرستید. همین توکن روی هر دو آدرس پایه کار می‌کند.

curl
$ curl https://api.manageit.dev/api/v1/projects \
    -H "Authorization: Bearer $MANAGEIT_TOKEN" \
    -H "Accept: application/json"
✓ 200 OK · application/json
